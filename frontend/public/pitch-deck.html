PROJECT PRESENTATION

VoicePrint

A fully local voice-biometric platform for speaker enrollment and verification

Presented by: BATTIPROLU KARTHIK
1 / 11

The Problem

Passwords & OTPs Are Fragile

Easily phished, intercepted, shared, or forgotten. High user friction with frequent lockouts and password resets.

Voice Is a Natural Identifier

Zero cognitive effort. Hands-free authentication that works across any device equipped with a basic microphone.

Cloud Voice APIs Leak Privacy

Transmitting raw voice audio to third-party cloud servers creates critical data security, compliance, and eavesdropping risks.

Traditional Systems Are Inflexible

Classical biometric models require heavy setup, high compute, and extensive labelled datasets for every new speaker.

How can we verify who is speaking accurately, in real time, and 100% offline without voice data ever leaving the device?

Proposed Solution

VoicePrint: A self-contained, zero-cloud biometric platform that converts voice samples into a compact 192-dimensional voiceprint and validates identity via neural cosine similarity in real time.

🎙️ Voice Enrollment

Generates speaker profiles from sample audio with automated validation, normalization, and statistical outlier filtering.

⚡ Real-Time Live Verification

Instant speaker verification via live microphone streaming with responsive waveform visualization and confidence gauge.

📂 Batch Verification

Automated multi-clip verification against stored profiles with visual analytics and similarity score metrics.

🔒 100% Offline & Private

Zero cloud dependencies. All deep neural inferences run locally on standard CPU without transmitting data externally.

4 / 11

What We Have Implemented

  • End-to-End Audio Pipeline: Automated WAV validation, 16 kHz mono resampling, loudness normalization (RMS), and clipping detection.
  • Neural Embedding Engine: Integrated ECAPA-TDNN deep network extracting dense 192-dimensional speaker embeddings.
  • Outlier Rejection Enrollment: Statistical filtering that isolates clean speaker samples and computes robust centroid voiceprints.
  • Fast Cosine Scoring: High-precision cosine distance matching with configurable thresholds (default 0.70) and confidence scoring.
  • Interactive Web Interface: Live audio verification dashboard with instant pass/fail verdict, score gauges, and profile management.
  • Production Full-Stack Architecture: Modular FastAPI REST & WebSocket backend combined with an accessible web frontend.

Is This the Optimal Approach?

Why This Approach Is Optimal

  • State-of-the-Art Accuracy: ECAPA-TDNN leverages squeeze-and-excitation and multi-scale aggregation, outperforming classic x-vectors.
  • Zero Retraining Required: Deep embeddings generalize across unseen speakers; creates voiceprints with only a few audio samples.
  • Efficient CPU Inference: Sub-second verification without requiring expensive GPU infrastructure.
  • Privacy-by-Design: Biometric embeddings never leave the device, fully eliminating compliance risks.

Honest Trade-offs & Challenges

  • Anti-Spoofing: Replay attacks and synthetic deepfake speech require an additional liveness detection module.
  • Short Utterance Variance: Audio clips under 1.5 seconds have reduced verification confidence.
  • Threshold Calibration: Variable microphone hardware and background noise require deployment-specific tuning.
  • Storage Scale: File-based .npy storage is optimal for edge/local prototypes, needing DB clustering for massive user bases.

Future Enhancements

  • Anti-Spoofing & Liveness Detection: Implement spectral analysis and synthetic voice classifiers to thwart deepfake & replay attacks.
  • Text-Dependent Dynamic Prompts: Challenge-response phrases (e.g., randomized digit verification) for high-security applications.
  • Adaptive Noise Suppression: Integrated real-time neural speech enhancement for noisy real-world acoustic environments.
  • Encrypted Vector Database: Scale to millions of enterprise profiles using AES-256 encrypted vector indices (e.g., Milvus / pgvector).
  • Edge & Mobile SDK: Quantize model with ONNX Runtime / CoreML for instant on-device authentication on Android and iOS.
  • Continuous Profile Adaptation: Gradual voiceprint updating to account for natural vocal changes over time.
